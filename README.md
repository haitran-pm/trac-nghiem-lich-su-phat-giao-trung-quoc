# Trắc nghiệm Lịch sử Phật giáo Trung Quốc

Website tĩnh gồm 300 câu trắc nghiệm từ 6 file PDF.

## Sử dụng

Mở `index.html` bằng trình duyệt, không cần máy chủ. Có thể tải toàn bộ thư mục lên GitHub Pages.

## Đáp án

299 câu có đáp án xác định từ PDF (1/1: lựa chọn được đánh dấu; 0/1: trường Correct answer). Bài 2, câu 39 không có đáp án hiển thị trong PDF, nên được giữ ở trạng thái chưa xác minh.

Tất cả đáp án chỉ phản ánh nguồn PDF, chưa được thẩm định độc lập.
